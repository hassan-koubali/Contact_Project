## Contact_Project

- Contact_Project is a simple C# application for managing contacts.
- It allows users to create, read, update, and delete (CRUD) contacts efficiently using a clean and interactive interface.


---

## 📝 Features

- Add new contacts with details (name, phone, email, etc.)

- View all contacts

- Edit existing contact information

- Delete contacts

- Search contacts by name or other details

- Simple and user-friendly interface



---

## Technologies Used

- C#

- Windows Forms / Console Application (depending on your version)

- File handling or in-memory storage for contact data

- Object-Oriented Programming (OOP)



---

## Future Improvements

- Store contact data in a database (SQL/SQLite)

- Add search filters and sorting options

- Improve the UI for better usability



---

## About

- Contact_Project is a C# project designed to practice CRUD operations, OOP, and basic application design.
